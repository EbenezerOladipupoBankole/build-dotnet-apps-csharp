# Build .NET Applications with C#

My work for the Microsoft Learn "Build .NET Applications with C#" modules, built with the .NET 10 LTS SDK.
See [NOTES.md](NOTES.md) for the submission evidence: the pizza seed data, the CRUD request and response examples, and the sales summary function.

Run any project with `dotnet run` from inside its folder:

- `01-FirstCSharpCode`: C# syntax basics
- `02-IntroToDotNet`: small .NET console app
- `03-DotNetDependencies`: NuGet dependency (Humanizer)
- `04-DotNetDebugging`: Fibonacci bug fixed with the VS Code debugger (`.vscode` launch config included)
- `05-FilesAndDirectories`: totals sales files and writes `salesTotalDir/salesSummary.txt`
- `06-ContosoPizza`: ASP.NET Core controller web API with CRUD at `/pizza`
